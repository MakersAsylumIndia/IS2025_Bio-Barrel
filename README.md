# 📘 Welcome to the Bo-Barrel repository!

Composting organic waste in a barrel is an efficient way to manage waste, but it commonly faces challenges related to moisture balance, aeration & pests. Barrels offer convenience, but often require active management to avoid turning waste into a smelly, anaerobic sludge.

We built an electronics package of sensors & WiFi+Bluetooth microcontroller that helps monitor / report data. We used DHT-11 for temp/humidity, Capacitive sensor for moisture, MQ135 for gases, and pH sensor for pH levels.
